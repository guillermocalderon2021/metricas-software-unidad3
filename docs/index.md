# Métricas de Software

Este sitio contiene el material de referencia del curso **Métricas de Software**.

El curso estudia la obtención, interpretación y utilización de evidencia para comprender el comportamiento de sistemas de software y sustentar decisiones técnicas.

## Unidad III. Instrumentación y observabilidad

La Unidad III estudia cómo diseñar y producir telemetría útil para analizar sistemas en ejecución. La secuencia prevista es:

1. Observabilidad y diseño de telemetría.
2. Logging estructurado.
3. Prometheus e instrumentación de métricas.
4. PromQL y análisis de series temporales.
5. Dashboards y alertas.
6. OpenTelemetry.
7. Trazas distribuidas y correlación de señales.
