# Unidad III. Instrumentación y observabilidad

La unidad estudia la producción y el análisis de evidencia operacional generada por aplicaciones y servicios.

El objetivo no es acumular telemetría, sino diseñar señales que permitan responder preguntas sobre el comportamiento del sistema con un costo y un nivel de detalle justificables.
